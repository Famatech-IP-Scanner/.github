## Overview

Famatech IP Scanner is a LAN analysis concept built around network device discovery and remote access. It brings together shared folder access, RDP and Radmin integration, and portable deployment into a single Windows utility for network administrators.

---

## Essential Famatech IP Scanner Features

- **Network Device Discovery:** Scan IP ranges to detect all devices on the LAN, including computers, servers, and network equipment.
- **Shared Folder Access:** Connect directly to shared folders on discovered devices with a single click.
- **Remote Control Integration:** Launch RDP sessions or Radmin connections to discovered computers where the respective software is installed.
- **MAC Address Detection:** Retrieve MAC addresses and NetBIOS names for scanned devices.
- **Remote Power Management:** Switch computers on or off remotely, including Wake-on-LAN support.
- **Portable Deployment:** Run the utility without installation, making it suitable for USB drives and temporary access.

## What Famatech IP Scanner Brings to Network Administration

The utility provides a focused environment for LAN analysis and device management. Its structure supports both quick network surveys and ongoing administrative tasks.

Multithreaded scanning delivers speed on large networks. The scan engine can process hundreds of computers at once, and scan speed, timeout, and retry settings are configurable to balance performance and accuracy.

Built-in tools reduce context switching. Ping, Tracert, Telnet, and SSH can be launched directly from the scan results, allowing administrators to diagnose connectivity issues without leaving the interface.

Radmin integration extends the tool beyond discovery. When Radmin Server is detected on a remote computer, the scanner can initiate a remote control session directly, connecting network mapping with hands-on management.

Result management supports repeatable workflows. Scan results can be exported to CSV for use in spreadsheets, and frequently accessed computers can be added to a Favorites list that saves in XML, HTML, or CSV formats.

Remote power controls add operational convenience. Administrators can shut down, restart, or wake computers across the network without physically visiting each machine.

Compatibility spans modern Windows versions. The utility supports Windows 11, 10, 8, and 7, and runs as a portable edition without requiring installation.
